The skills

Claude Code skills are the working knowledge of the studio: the workflow, the rules and the checks, written down so any session can pick them up.

What a skill is

A skill is a folder with a SKILL.md: a short description that tells Claude when to use it, the instructions themselves, and optional references/ and templates/ pages that are read only when the task needs them. Claude loads a skill when your request matches its description, so you can also just name it.

8 skills here (6 personal, 2 vendored), with 38 reference and template pages. Every one is rendered on this site.

Install them

From the repository root, copy every skill into ~/.claude/skills/:

node tools/install-skills.mjs

Preview first with --dry-run, or install only some by name:

node tools/install-skills.mjs --dry-run
node tools/install-skills.mjs remotion-studio motion-review

A changed installed skill is moved to a timestamped backup before it is replaced, and an identical one is left alone.

Which skill when

Start from what you want to do, not from the skill name.

You want toUseKind
Before building: brief, directions, storyboard, reference breakdown, plan review.motion-directorPlanning, no code

Which engine?

Use remotion-studio by default. Switch to motion-studio only for a narrated product film where every cut lands on a spoken word. Plan with motion-director first, and finish with motion-review on the render.
