What it is

Deterministic frames

Every frame is a pure function of the frame number: useCurrentFrame, interpolate, spring. No CSS transitions, timers or Math.random, so a still and a render always agree.

Reusable components

14 small components in src/lib: titles, staggered text, captions, counters, charts, masks, sound. Prop-driven, frame-local, safe by default.

One folder per video

Each film lives in src/videos/<slug>/ with its scenes and a timeline file, registered in Root.tsx. Copy the template to start.

Design tokens

Palette, type scale, spacing, safe margins, springs, easing and timing live in one tokens file. Change values there, never inline in a scene.

Quick start

Prerequisites: Node 24 (or 20.19+ / 22.13+), ffmpeg on PATH (for stills contact sheets and sfx).

cd studio
npm install
npm run typecheck                                   # tsc --noEmit
npm run stills -- LibraryShowcase 50,130,245,350,449  # PNGs + contact sheet in out/stills/LibraryShowcase/
npm run render -- LibraryShowcase out/LibraryShowcase.mp4
npm run dev                                         # Remotion Studio preview (long-running; stop with Ctrl+C)

Start a new video

  1. Copy src/videos/_template/ to src/videos/<slug>/; rename Template to your video's name.
  2. One component per scene (copy Scene.tsx), one focal point per scene, built from src/lib components and tokens only.
  3. Chain scenes in a <TransitionSeries>, with presets.wipe() / fade() / circle() and transitionTiming() between them. Duration = sum of scenes - 15 frames per transition. Keep scene lengths in a timeline.ts like the showcase does.
  4. Register the composition in src/Root.tsx inside a <Folder>, with inline id, fps={30}, width, height, durationInFrames.
  5. Judge rendered frames, not code: npm run stills -- <CompId> <scene boundaries, text-heavy frames, mid-transition frames, last frame>, open the PNGs, fix, repeat. Then render the MP4 and check it with ffprobe.

The paper trail for each video (brief, storyboard, review) lives in ../projects/<yyyy-mm-dd>-<slug>/, see the repo CLAUDE.md.

New helpers from the research

Techniques that earned a place in the library after the Claude motion research. Each links to the finding it came from.

buoyant()

"Buoyant" ease: a cubic ease-out plus a half-sine bob over the WHOLE lifetime, so a rising element keeps drifting through its peak instead of freezing. Returns 0 at t=0 and exactly 1 at t=1; in between it overshoots by about bob and settles back.

In the catalogue

FragmentChain

Film copy as fragments, not sentences (F-A2). Recipes: the animation is the verb (words before and after the demo, never describing it), stem plus rotating slot instead of a list. One accent per frame: only the newest fragment is accented.
