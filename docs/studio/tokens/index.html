Safe margins per format

Key text and logos stay inside the inner box. 9:16 reserves extra room at the top and bottom for platform interface. Re-compose for each format instead of scaling.

Spring presets

Plotted over two seconds with the same step the Remotion spring() function takes each frame. The dashed line is the target.

springs.smooth

No overshoot. Default for text, masks, panels.

damping 200, stiffness 100, mass 1
overshoot 0.0%, settles in about 23 frames

springs.snappy

Quicker, no visible overshoot. Small UI elements, bars.

damping 28, stiffness 220, mass 0.7
overshoot 0.0%, settles in about 13 frames

springs.settle

Tiny overshoot, then settle. One element per scene at most.

damping 18, stiffness 120, mass 1
overshoot 1.1%, settles in about 20 frames

Easing curves

Bezier curves for interpolate(). Never animate linearly unless it is a counter or a constant drift.

ease.out

Default for entrances: fast start, long soft landing.

cubic-bezier(0.16, 1, 0.3, 1)

ease.in

For exits: gentle start, quick finish.

cubic-bezier(0.7, 0, 0.84, 0)

ease.inOut

For moves between two resting states and wipes.

cubic-bezier(0.65, 0, 0.35, 1)

buoyant()

"Buoyant" ease: a cubic ease-out plus a half-sine bob over the WHOLE lifetime, so a rising element keeps drifting through its peak instead of freezing. Returns 0 at t=0 and exactly 1 at t=1; in between it overshoots by about bob and settles back.

plotted with the default bob of 0.03 from the formula in its doc comment
